# Clustering News Articles with Word Vectors

Group news articles by topic without labels.

## Approach

- Text preprocessing with NLTK
- TF-IDF and Word2Vec document representations
- KMeans clustering with silhouette evaluation and t-SNE visualisation

## Results

Silhouette scores between about 0.76 and 0.92 in the saved notebook output.

## Start here

[ClusteringText.ipynb](ClusteringText.ipynb)

## Data

20 Newsgroups, a public dataset that can be downloaded through scikit-learn.
